# Hajj & Umrah Agency Website

A modern, responsive, and scalable Hajj & Umrah agency website built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## 🚀 Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Lucide React
- Next/Image
- Next/Link

---

## ✨ Features

- Responsive Design
- Mobile First Layout
- SEO Friendly
- Sticky Navbar
- Active Route Navigation
- Modern Hero Section
- Hajj Packages Section
- Umrah Packages Section
- Team Section
- Contact Section
- Office Location Section
- Google Maps Integration
- WhatsApp Integration
- Reusable Components
- Clean Folder Structure

## 🎯 Development

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```

### Start Production Server

```bash
npm run start
```
